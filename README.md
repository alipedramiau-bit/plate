# 🇮🇷 سامانه جامع و هوشمند بینایی ماشین و تشخیص پلاک خودروهای ایرانی (Iranian ANPR System)

یک سامانه صنعتی، مدرن و یکپارچه مبتنی بر **بینایی ماشین (OpenCV)**، **پردازش تصویر**، **Tesseract OCR با مدل آموزش‌دیده فارسی** و پایگاه داده رابطه‌ای **SQLite** برای تشخیص و تفکیک اجزای پلاک‌های ملی ایران (خودروهای سواری، تاکسی، دولتی، عمومی و موتورسیکلت‌های دوخطی).

---

## 🌟 ویژگی‌های کلیدی سامانه

### ۱. هسته بینایی ماشین و هوش مصنوعی واقعی (Computer Vision & ANPR)
- **پیش‌پردازش با فیلتر دوطرفه (Bilateral Filter):** کاهش نویز فریم‌ها در شرایط کم‌نور، دید در شب و دوربین‌های مداربسته شهری ضمن حفظ وضوح لبه‌های کاراکترها.
- **استخراج گرادیان سوبل افقی (Sobel X Gradient):** هایلایت لبه‌های عمودی حروف و اعداد پلاک.
- **بستن مورفولوژیکی (Morphological Closing):** ادغام فاصله بین حروف و اعداد به صورت یک کاندیدای مستطیلی یکپارچه.
- **فیلتر کانتور با نسبت منظر استاندارد پلاک ایران (Aspect Ratio):** غربالگری هوشمند کانتورهای با نسبت عرض به ارتفاع بین ۲.۰ تا ۵.۸ (پلاک خودرو استاندارد ایران ~ ۴.۵۶).
- **ماسک رنگی نوار آبی پرچم ایران (HSV Mask):** تشخیص نوار آبی پرچم جمهوری اسلامی ایران در حاشیه سمت چپ پلاک (`H: 90–135, S: 70–255, V: 50–255`) جهت رد کاندیداهای کاذب.
- **خوانش با Tesseract OCR 5.3 (فارسی و انگلیسی):** بزرگنمایی ۲.۵ برابری کیوبیک، آستانه‌گیری تطبیقی گوسی و استخراج دقیق متن پلاک به فرمت استاندارد:
  $$\text{۲ رقم} \quad + \quad \text{حرف فارسی} \quad + \quad \text{۳ رقم} \quad + \quad \text{ایران [کد استان]}$$

### ۲. فرانت‌اند مدرن با React + Vite + Tailwind CSS
- **نمایشگر گرافیکی واقع‌گرایانه پلاک ملی:** رندر پلاک با نوار آبی، نشان پرچم ایران، حرف وسط و کد استان بر اساس استانداردهای پلیس راهور.
- **پایش و تحلیل لحظه‌ای دوربین‌های پخش زنده (Live IP Camera / HLS / RTSP / HTTP):**
  - اتصال به جریان‌های زنده اینترنتی ترافیکی
  - فعال‌سازی پایش خودکار با کادرهای ردیابی متحرک هوش مصنوعی (AI Bounding Box HUD)
  - ثبت بلادرنگ پلاک‌های عبوری در پایگاه داده بدون نیاز به اسکن دستی
  - هشدار صوتی ملایم و فلش تصویری اختصاصی در زمان شناسایی هر پلاک
- **آپلود مستقیم ویدیو:** قابلیت Drag & Drop فایل‌های ویدیویی کاربر در فرمت‌های MP4, MKV, AVI, MOV, WebM با نوار پیشرفت بارگذاری و پردازش فریم‌به‌فریم با پایتون.
- **مرورگر پایگاه داده SQLite:** جدول پیشرفته با امکان جستجوی لحظه‌ای، فیلتر بر اساس استان، خودرو و تاریخ رویت، حذف رکورد و دانلود مستقیم فایل `plates.db` و خروجی‌های CSV و JSON.
- **نمایشگر خط فرمان و ترمینال پایتون:** تب اختصاصی برای مشاهده کدهای هسته ANPR، کدهای تست و اجرای زنده تست‌های واحد در محیط وب.

### ۳. پایگاه داده استاندارد SQLite با جلوگیری از تکرار داده‌ها
- جدول `detected_plates`: نگهداری بخش‌های تفکیک‌شده پلاک، نام و کد استان، نوع خودرو، درصد اطمینان هوش مصنوعی، ثانیه رویت در ویدیو، مسیر تصویر فریم و تصویر کراپ‌شده پلاک.
- جدول `detection_logs`: تاریخچه تمامی دفعات عبور خودرو با ثبت کلید خارجی به جدول اصلی.
- افزایش خودکار شمارنده رویت (`detection_count`) در صورت تکرار تردد بدون اضافه کردن رکوردهای هرز.

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. نصب پیش‌نیازهای سیستمی (OpenCV, FFmpeg, Tesseract با زبان فارسی)
در سیستم‌عامل‌های لینوکس پایه دبیان/اوبونتو:
```bash
sudo apt update
sudo apt install -y python3 python3-pip ffmpeg \
    tesseract-ocr tesseract-ocr-fas tesseract-ocr-eng \
    python3-opencv python3-numpy python3-pil
```

### ۲. نصب وابستگی‌های پایتون
```bash
pip install -r requirements.txt
```

### ۳. نصب وابستگی‌های فرانت‌اند
```bash
npm install
```

### ۴. اجرای برنامه
```bash
# اجرای هم‌زمان فرانت‌اند React و سرور با هم
npm run dev
```
برنامه در آدرس پیش‌فرض `http://localhost:3000` در دسترس خواهد بود.

## 🧪 تست‌های خودکار (Automated Testing)

برای اطمینان از سلامت عملکرد الگوریتم‌های پردازش تصویر و پایگاه داده:
```bash
python3 test_anpr.py
```

این اسکریپت ۴ مرحله زیر را به‌طور خودکار راستی‌آزمایی می‌کند:
1. ایجاد پایگاه داده SQLite و بررسی تمامی ستون‌ها و ایندکس‌ها.
2. درج نمونه پلاک و بررسی تطبیق نام استان با کد پلاک ملی.
3. عدم ایجاد رکورد تکراری و افزایش شمارنده رویت (`detection_count`).
4. اجرای الگوریتم روی ویدیوی مداربسته و استخراج تمام خودروهای عبوری.

## 📡 مستندات API (REST Endpoints)

| مسیر (Route) | متد | توضیحات |
| :--- | :--- | :--- |
| `/api/plates` | `GET` | دریافت فهرست کامل پلاک‌های ثبت‌شده در دیتابیس |
| `/api/plates` | `POST` | درج یا به‌روزرسانی دستی پلاک در دیتابیس |
| `/api/plates/:id` | `DELETE` | حذف رکورد پلاک مشخص بر اساس شناسه |
| `/api/plates/clear` | `POST` | پاکسازی کامل رکوردهای دیتابیس |
| `/api/upload-video` | `POST` | آپلود فایل ویدیو و اجرای تحلیل خودکار فریم‌ها |
| `/api/analyze-live-stream` | `POST` | دریافت فریم از دوربین یا استریم زنده، اجرای OpenCV و ثبت خودروها |
| `/api/scan-all-live` | `POST` | استخراج جامع تمام پلاک‌های کلیپ در یک مرحله |
| `/api/download-db` | `GET` | دانلود مستقیم فایل دیتابیس `plates.db` |
| `/api/export-csv` | `GET` | دانلود خروجی گزارش با فرمت CSV اکسل |
