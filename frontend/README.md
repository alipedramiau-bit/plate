# بخش فرانت‌اند سامانه هوشمند پلاک‌خوان ایرانی (Frontend)

این دایرکتوری شامل رابط کاربری مدرن، تعاملی و واکنش‌گرای وب سیستم تشخیص پلاک خودروهای ایرانی است که با **React 18+/19**، **Vite** و **Tailwind CSS 4** با پشتیبانی کامل از چینش راست‌به‌چپ (RTL) و فونت فارسی وزیزمتن توسعه داده شده است.

---

## 🚀 ویژگی‌های کلیدی فرانت‌اند

1. **نمایش واقع‌گرایانه پلاک ایرانی (`PersianPlate`):**
   - نوار آبی استاندارد پرچم جمهوری اسلامی ایران (`I.R. IRAN`).
   - فونت استاندارد خوانا، تفکیک ۲ رقم، حرف فارسی، ۳ رقم و شناسه ۲ رقمی استان.
   - پشتیبانی از پلاک‌های عمومی (ع)، تاکسی (ت)، دولتی (الف)، گذر موقت (گ) و موتورسیکلت دوخطی.

2. **تحلیل زنده دوربین‌های ترافیکی و استریم اینترنتی (`LiveStreamAnalyzer`):**
   - پیش‌تنظیم دوربین‌های بزرگراه شهید همت، تقاطع ولیعصر و نظارت شبانه.
   - پشتیبانی از پروتکل‌های ویدیویی زنده اینترنتی (HLS `.m3u8`، RTSP، WebM، MP4).
   - اسکن فریم زنده و پایش خودکار هوشمند با بازه‌های زمانی قابل تنظیم.
   - ترسیم لحظه‌ای باکس‌های هوش مصنوعی (AI Bounding Box) با مختصات درصدی واکنش‌گرا.

3. **آپلودر پیشرفته فایل‌های ویدیویی (`VideoUploader`):**
   - درگ اند دراپ فایل‌های ویدیویی نظارتی (MP4، MKV، AVI، WebM).
   - نوار پیشرفت آپلود و ارسال آنی به پایگاه داده با خط فرمان پایتون.

4. **نوار پلاک‌های شناسایی شده در پایین صفحه (`BottomPlateTicker`):**
   - نمایش کارت‌های متحرک پلاک‌های تازه کشف شده با دکمه‌های مستقیم دریافت فایل اکسل (CSV) و JSON.

5. **جدول و مرورگر جامع پایگاه داده (`PlateTable`):**
   - فیلتر بر اساس حروف فارسی، استان‌ها و نوع خودرو.
   - جستجوی بلادرنگ در پلاک‌های ثبت شده.
   - دکمه‌های مستقیم خروجی استاندارد **CSV** (دارای هدر UTF-8 BOM جهت نمایش بی‌نقص در Excel) و **JSON**.

6. **مشاهده‌گر زنده کدهای پایتون (`PythonCodeViewer`):**
   - نمایش کدهای بینایی ماشین و تست‌های خودکار مستقیماً در مرورگر.

---

## 🛠 راه‌اندازی و اجرای مستقل فرانت‌اند

```bash
# رفتن به پوشه فرانت‌اند
cd frontend

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه Vite روی پورت ۵۰۰۲ (با پروکسی خودکار به وب‌سرویس FastAPI روی پورت ۸۰۰۲)
npm run dev
# آدرس دسترسی در مرورگر: http://localhost:5002

# بررسی سلامت تایپ‌های TypeScript
npm run lint

# ایجاد خروجی بهینه‌سازی شده برای استقرار نهایی
npm run build
```

```
│   │   ├── LiveStreamAnalyzer.tsx # ماژول مانیتورینگ زنده دوربین‌ها و ترسیم باکس
│   │   ├── PersianPlate.tsx       # کامپوننت گرافیکی پلاک ملی ایران
│   │   ├── PlateTable.tsx         # جدول جامع پلاک‌ها با فیلتر و خروجی CSV/JSON
│   │   ├── PythonCodeViewer.tsx   # نمایش کدهای پایتون در محیط وب
│   │   └── VideoUploader.tsx      # فرم آپلود ویدیو با پیش‌نمایش
│   ├── App.tsx                    # مولفه اصلی سامانه و مدیریت تب‌ها
│   ├── index.css                  # استایل‌های Tailwind CSS 4 و فونت Vazirmatn
│   └── main.tsx                   # نقطه ورود React به DOM
├── index.html                     # سند اصلی با متاتگ‌های سئو و فونت فارسی
├── package.json                   # وابستگی‌ها و اسکریپت‌های مستقل فرانت‌اند
├── tsconfig.json                  # پیکربندی TypeScript
├── vite.config.ts                 # پیکربندی Vite با پروکسی خودکار به پورت 3000
└── README.md                      # مستندات فرانت‌اند
```
