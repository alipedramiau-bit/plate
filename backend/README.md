# بخش بک‌اند سامانه هوشمند پلاک‌خوان ایرانی (Backend)

این دایرکتوری شامل موتور اصلی پردازش تصویر، بینایی ماشین، یادگیری ماشین برای نویسه‌خوان نوری (Tesseract OCR فارسی و انگلیسی)، وب‌سرویس مدرن **FastAPI** و تست‌های خودکار است.

---

## 🧠 معماری و ساختار پردازش تصویر (`anpr_system.py`)

خط لوله بینایی ماشین بر پایه کتابخانه‌های پیشرفته **OpenCV** و **PyTesseract** طبق مراحل زیر عمل می‌کند:
1. **دریافت فریم و مقیاس‌گذاری:** خواندن فریم از وب‌کم، ویدیو، استریم RTSP/HLS با ابعاد پایدار $1280 \times 720$.
2. **پیش‌پردازش تصویر:** تبدیل به تصویر خاکستری (Grayscale) و فیلتر دوطرفه Bilateral جهت حذف نویزهای محیطی در عین حفظ لبه‌های تیز پلاک.
3. **آشکارسازی لبه‌ها با عملگر Sobel X:** تقویت لبه‌های عمودی کاراکترهای پلاک و اعمال بستن مورفولوژیکی (Morphological Closing).
4. **آستانه‌گذاری تطبیقی اتسو (Otsu Adaptive Binarization):** دو دویی کردن تصویر برای آشکارسازی کانتورها در شرایط نوری مختلف (شب و روز).
5. **فیلتر هندسی کانتورها:** بررسی نسبت طول به عرض پلاک‌های ایرانی ($2.0 \le \frac{w}{h} \le 5.8$) و برای موتورسیکلت‌ها ($1.2 \le \frac{w}{h} \le 2.2$).
6. **اعتبارسنجی نوار آبی رنگ پرچم ایران:** ماسک رنگی HSV در بازه $H \in [90, 135]$ برای سمت چپ پلاک.
7. **خوانش کاراکترها (OCR) با Tesseract 5.3:** استخراج همزمان ارقام و حروف با مدل‌های زبانی `fas` و `eng`.
8. **پارس ساختار پلاک ملی:** ۲ رقم + حرف فارسی + ۳ رقم + کد استان و نام استان بر اساس پایگاه داده ۶۰ کد استانی کشور.
9. **ثبت غیرتکراری در SQLite:** ذخیره خودکار در `data/plates.db` با به‌روزرسانی شمارنده مشاهده و حفظ بهترین تصویر کراپ.

---

## ⚡ وب‌سرویس FastAPI (`main.py`)

سرویس RESTful پایتون با قابلیت‌های زیر:
- **مستندات اسواگر خودکار:** در مسیر `http://localhost:8002/docs` یا `http://localhost:8002/redoc`.
- **مسیر `/api/plates`:** دریافت فهرست پلاک‌های ذخیره شده.
- **مسیر `/api/upload-video`:** آپلود فایل ویدیویی و پردازش آنی.
- **مسیر `/api/analyze-live-stream`:** دریافت آدرس استریم زنده اینترنتی و اسکن در ثانیه مشخص.
- **مسیر `/api/export-csv`:** دانلود فایل اکسل با کدگذاری UTF-8 BOM.
- **مسیر `/api/export-json`:** دریافت داده‌ها با فرمت استاندارد JSON.

## 🧪 اجرای تست‌های جامع خودکار (`test_anpr.py`)

برای اعتبارسنجی ۱۰۰٪ عملکرد الگوریتم‌ها و ساختار پایگاه داده:

```bash
# اجرای تست‌ها
python3 backend/test_anpr.py
```

این اسکریپت ۴ آزمون اساسی را انجام می‌دهد:
1. راه‌اندازی دیتابیس SQLite و ایجاد کلیه جداول و ستون‌های مورد نیاز.
2. درج پلاک نمونه، تفکیک اجزا و نگاشت صحیح کد استان (مانند استان اصفهان یا تهران).
3. تست عدم درج پلاک‌های تکراری و افزایش شمارنده رویت.
4. پردازش ویدیوی نظارتی واقعی کاربر و استخراج پلاک‌های خودروهای عبوری.

## 🛠 راه‌اندازی و نصب پیش‌نیازها

```bash
# نصب پکیج‌های پایتون
pip install -r backend/requirements.txt

# اجرای مستقیم پردازش یک استریم یا ویدیو از طریق ترمینال:
python3 backend/anpr_system.py --stream "/assets/aistudio/VID_20261029_183130_849_4af72e51.mp4" --sec 26.0 --db data/plates.db

# اجرای وب‌سرویس FastAPI روی پورت اختصاصی 8002:
python3 backend/main.py
# یا با uvicorn:
uvicorn backend.main:app --host 0.0.0.0 --port 8002 --reload
```
